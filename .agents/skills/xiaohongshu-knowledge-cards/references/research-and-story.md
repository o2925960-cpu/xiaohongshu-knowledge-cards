## 选题评分

从输入中抽取 1–5 个候选选题，每项按 1–5 分快速判断：

| 维度 | 判断问题 |
| --- | --- |
| 小白价值 | 能解决一个真实困惑或纠正常见误解吗？ |
| 故事张力 | 有问题、转折、因果、冲突或反直觉点吗？ |
| 视觉表达 | 能用人物、物件、路径、对比或空间关系画出来吗？ |
| 事实可靠性 | 能由高质量来源支持且不过度依赖猜测吗？ |
| 单组承载度 | 能在一组图里形成闭环，而不是百科全书吗？ |

优先推荐总分最高且不存在事实硬伤的主题。分数接近时，选择更贴近日常使用情境、可用一句话说清价值的主题。不要向用户倾倒完整评分过程；只展示推荐理由和必要的取舍。

## 输入类型处理

### 单个关键词

搜索术语的主流定义、当前语境和常见歧义。不要默认用户想看百科式定义；寻找“小白最容易误会什么”或“为什么现在需要懂它”。

### 多个关键词

先判断是并列词解、上下游关系、包含关系还是容易混淆的概念。能形成一条机制链时优先讲关系；关系不足时选一个主词，其余作为后续选题。

### 长文或文章片段

先抽取主张、证据、案例和隐含假设，再判断哪一个知识片段最适合单独传播。不要把原文目录直接变成页序。核验原文中的事实，不因用户提供而默认正确。

### 文件、截图或混合素材

先检查可见内容、标题、图表、来源线索和上下文缺口。说明哪些内容可确认、哪些只是推测。只有影响主线的缺失信息才向用户询问。

## 研究记录

搜索后在内部建立以下记录，并在方案中压缩呈现：

| 项目 | 内容 |
| --- | --- |
| 一句话定义 | 不依赖类比也准确的定义 |
| 为什么重要 | 对目标读者的直接意义 |
| 如何工作/使用 | 2–4 个最关键步骤 |
| 适用边界 | 不能做什么、何时不适用 |
| 常见误区 | 最值得纠正的 1–3 项 |
| 来源 | 原始来源及第二来源 |
| 时效 | 版本、发布日期或检索日期 |

优先讲稳定共识。对争议观点使用“通常”“在……条件下”“一种常见做法”等准确措辞。

## 消歧规则

满足任一条件时需要澄清：

- 同一词在本主题中存在两种以上主流含义。
- 不同含义会改变定义、受众、故事或结论。
- 输入的缩写无法从上下文可靠展开。
- 用户要求的“怎么用”可能指个人使用、产品实现或商业应用。

先搜索确认歧义真实存在，再问一个高信息量问题。示例：

> 这里的 Agent，你想讲“普通用户如何使用 AI 智能体”，还是“开发者如何搭建 Agent”？两者的故事线和技术深度会完全不同。

若上下文已足够明确，直接写明“本组按……理解”，不要为形式而提问。

## 常用故事结构

### 概念词解：建议 5–7 张

1. 封面：提出核心困惑。
2. 痛点：展示没有这个概念时发生什么。
3. 类比：用熟悉场景建立直觉。
4. 定义：给出准确、简短的概念边界。
5. 机制：展示 2–4 步如何运作。
6. 使用：给出一个贴近日常的例子。
7. 收束：误区、边界或一句话复述。

### 知识片段：建议 4–6 张

1. 封面：反常识结论或真实问题。
2. 现象：读者能认出的场景。
3. 原因：解释关键机制。
4. 模型：形成可迁移的理解框架。
5. 行动：告诉读者如何判断或应用。
6. 收束：一句话记忆钩子。

### 概念对比：建议 5–7 张

1. 封面：明确比较问题。
2. 共同任务：先说二者都在解决什么。
3. A：一个场景讲清角色和边界。
4. B：用相同场景保持可比性。
5. 对比：只展示决定选择的维度。
6. 选择：什么情况下用谁。
7. 收束：避免非黑即白的误区。

结构只是起点。删除没有信息增量的页面；复杂主题可增加机制或案例页。

## 分页与文字密度

- 封面只保留主标题、可选副钩子和固定角标。
- 内容页使用一个短标题、1–3 个短文本组和一个主画面。
- 每个文本组尽量是一句话；能由画面表达的内容不要重复写成长段。
- 把术语第一次出现时解释清楚，后续保持同一称呼。
- 每页结论应能被单独复述，但脱离整组时不应产生反向误导。
- 不把来源列表、长网址、完整论文名塞进图片；放在最终文字交付中。

## 生成前确认模板

使用紧凑格式输出：

```markdown
推荐选题：……
一句话价值：……
概念口径：本组按……理解
核验摘要：……
建议张数：共 X 张（至少 4 张）
角标关键词：……（不超过 4 个字符）

| 页码 | 页面任务 | 核心文案 | 画面故事 |
| --- | --- | --- | --- |
| 1 | 封面 | …… | …… |

视觉：灰白实体纸张 + 手绘故事 + 荧光笔强调 + 固定角标
请确认选题、X 张页数和逐页故事板；确认后再生成整组图片。
```
